# Data cases

Each file is an alternative content set for batches.txt, not an extra input file to read at the same time. Put the chosen contents in DispatchAudit/batches.txt before a run. Restore normal.txt contents before submission. A missing-file case is created by temporarily renaming batches.txt; there is intentionally no missing.txt fixture.

The brief defines the outcomes. This folder provides data, not a parser or solution. Input data files may be copied; write the C++ yourself.
